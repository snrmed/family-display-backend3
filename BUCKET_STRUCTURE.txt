## File Formats

### Designer HTML
- **Path:** `web/designer/overlay_designer_v4_clean.html`
- **Type:** HTML file
- **Served at:** `/designer/`
- **Purpose:** Layout editor interface

### SVG Assets
- **Path:** `assets/svgs/*.svg`
- **Format:** SVG XML
- **Accessed via:** `/gcs/assets/svgs/filename.svg`
- **Used in:** Layout elements

### Weather Icons
- **Path:** `assets/weather-icons/{theme}/{code}.svg`
- **Themes:** happy-skies, soft-skies, sunny-day, blue-sky-pro
- **Codes:** 01d, 01n, 02d, 02n, 03d, 04d, 09d, 10d, 10n, 11d, 13d, 50d, unknown
- **Auto-selected:** Based on device config `iconTheme`

### Pexels Images
- **Path:** `pexels/current/{category}_{number}.jpg`
- **Naming:** `abstract_0.jpg`, `geometric_1.jpg`, etc.
- **Categories:** Detected automatically from filenames
- **Selection:** Random from selected category

### Device Config
- **Path:** `devices/{device_id}/config.json`
- **Format:**
```json
{
  "location": {
    "city": "Darwin",
    "timezone": "Australia/Darwin"
  },
  "preferences": {
    "iconTheme": "happy-skies"
  }
}
```

### Layout File
- **Path:** `devices/{device_id}/layouts/current.json`
- **Format:**
```json
{
  "name": "Layout Name",
  "meta": {
    "iconTheme": "happy-skies",
    "pexelsCategory": "abstract"
  },
  "elements": [
    {
      "kind": "text|icon|box|svg-overlay",
      "x": 0,
      "y": 0,
      "width": 100,
      "height": 100,
      ...
    }
  ]
}
```

### Rendered Frame
- **Path:** `devices/{device_id}/renders/latest.png`
- **Format:** PNG image (800×480)
- **Generated:** By Playwright from base.html + layout

## Upload Priority

### Essential (Required for basic operation)
1. ✅ Designer HTML
2. ✅ Device config
3. ✅ Device layout (can be empty)

### Recommended (For full features)
4. ⭐ Weather icons (at least one theme)
5. ⭐ SVG assets (for visual elements)
6. ⭐ Pexels images (for backgrounds)

### Auto-Generated
- ✨ Rendered frames (created by backend)

## Size Guidelines

| Asset Type | Recommended Size | Notes |
|-----------|------------------|-------|
| Designer HTML | < 500 KB | Single file with embedded CSS/JS |
| SVGs | < 50 KB each | Optimized vector graphics |
| Weather Icons | < 20 KB each | Simple icon designs |
| Pexels Images | 800×480 px, < 200 KB | Optimized for display |
| Config JSON | < 1 KB | Small text file |
| Layout JSON | < 50 KB | Element definitions |
| Rendered PNG | ~100-200 KB | Full frame image |

## Minimal Setup

To get started quickly, you only need:

```bash
# 1. Upload designer
gsutil cp backend/web/designer/overlay_designer_v4_clean.html \
  gs://family-display-packs/web/designer/overlay_designer_v4_clean.html

# 2. Create device structure
echo '{"name":"Default","elements":[]}' | \
  gsutil cp - gs://family-display-packs/devices/familydisplay/layouts/current.json

echo '{"location":{"city":"Darwin","timezone":"Australia/Darwin"},"preferences":{"iconTheme":"happy-skies"}}' | \
  gsutil cp - gs://family-display-packs/devices/familydisplay/config.json
```

Then set environment variables and deploy!
